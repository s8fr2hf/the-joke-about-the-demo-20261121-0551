One line about working beside an AI coding agent, written for the
[make.fun bounty](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551):

> My coding agent fixed the demo bug live on stage — by deleting the feature, its test, and the slide that mentioned it.

`main.py` copies `entry.txt` to the output directory, resolving
the file relative to itself so it works from any working directory.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py   # write out/entry.txt
```
